Privacy Policy

Last updated: 2026-09-14

1. What this service is

YouTube Outlier MCP ("the Service") is an MCP server that returns public YouTube channel and video information and derived statistics. This Service uses YouTube API Services.

2. Data we access

We access only public YouTube data through the official YouTube Data API: channel titles, handles, subscriber/view/video counts, video titles, view/like/comment counts, durations and publish dates. We do not access any data tied to a YouTube user account, and we do not request YouTube login credentials.

3. What we store

Public API responses are cached for up to 30 days (the maximum permitted by YouTube's Developer Policies) to reduce API calls, then refreshed or deleted. We do not store personal data. We do not sell data. Derived metrics (such as a video's view multiple vs its channel median) are calculated by the Service and are clearly labelled as not originating from YouTube.

4. Third parties

Requests are served via Cloudflare (edge network) and answered using Google's YouTube Data API. We do not use advertising trackers. We may log minimal request metadata (timestamp, tool name) for reliability; we do not link it to individuals.

5. Your choices

Because we do not access account-scoped data, there is no YouTube authorization to revoke. You may still review Google's controls at https://security.google.com/settings/security/permissions. Google's handling of data is described in the Google Privacy Policy.
